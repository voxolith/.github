# .github

Organisation profile for [github.com/voxolith](https://github.com/voxolith) and the public home of
the brand assets used in READMEs (`profile/lockup.svg`, `profile/lockup-dark.svg`,
`profile/logo-mark.svg`). Assets are generated in the private `voxolith/branding` repo.

It also holds the organisation-wide community files, which GitHub uses for every repo that has
none of its own: [CONTRIBUTING](CONTRIBUTING.md), [CODE_OF_CONDUCT](CODE_OF_CONDUCT.md),
[SECURITY](SECURITY.md), the pull request template and the issue forms in `ISSUE_TEMPLATE/`.
